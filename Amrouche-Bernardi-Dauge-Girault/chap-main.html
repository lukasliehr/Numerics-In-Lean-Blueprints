Theorem 4.1 Theorem 3.12: tangential vector potentials
✓
#

Uses

  • Definition 3.5
  • Theorem 5.4
  • Theorem 5.8

Lean declarations

  • VP.tangentialPotential_iff
  • VP.theorem_3_12

Let \(\Omega \) carry admissible geometric data and let \(u\in L^2(\Omega )^3\). Then \(\operatorname {div}u=0\) and \(F_i(u)=0\) for \(0\le i\le I\) if and only if there is exactly one \(\psi \in L^2(\Omega )^3\) with

\[ \operatorname {curl}\psi =u,\qquad \operatorname {div}\psi =0,\qquad \psi \cdot n=0,\qquad C_j(\psi )=0\ (1\le j\le J). \]
Proof ▶

Theorem 5.4, applied with the analytic inputs of Theorem 5.8.

Let \(\Omega \) carry admissible geometric data and let \(u\in L^2(\Omega )^3\). Then \(\operatorname {div}u=0\), \(u\cdot n=0\) and \(C_j(u)=0\) for \(1\le j\le J\) if and only if there is exactly one \(\psi \in L^2(\Omega )^3\) with

\[ \operatorname {curl}\psi =u,\qquad \operatorname {div}\psi =0,\qquad \psi \times n=0,\qquad F_i(\psi )=0\ (0\le i\le I). \]
Proof ▶

Theorem 5.7, applied with the analytic inputs of Theorem 5.8.

2 Results from Mathlib

The formalization builds on Mathlib. The following definitions and results of Mathlib are its main ingredients; in the dependency graph they are grey, and their edges show where they enter the proofs.

Definition 2.1 The Hilbert space \(L^2\)
✓
#

Lean declarations

  • MeasureTheory.Lp
  • MeasureTheory.L2.innerProductSpace
  • MeasureTheory.Lp.instCompleteSpace

For a measure \(\mu \), the space \(L^2(\mu )\) of square-integrable functions, taken modulo equality almost everywhere, with its inner product; it is complete.

Definition 2.2 Test functions
✓
#

Lean declarations

  • TestFunction

The space \(C_c^\infty (\Omega )\) of smooth functions with compact support in an open set \(\Omega \).

Theorem 2.3 Orthogonal projection
✓
#

Lean declarations

  • Submodule.starProjection
  • Submodule.orthogonal_orthogonal_eq_closure

A complete subspace \(K\) of an inner product space has an orthogonal projection \(P_K\), with \(x-P_Kx\in K^\perp \); moreover \((K^\perp )^\perp =\overline K\).

Theorem 2.4 Riesz representation theorem
✓
#

Lean declarations

  • InnerProductSpace.toDual

Every bounded linear functional on a Hilbert space is of the form \(x\mapsto (y,x)\) for a unique \(y\).

Theorem 2.5 Closed graph theorem
✓
#

Lean declarations

  • LinearMap.continuous_of_isClosed_graph

A linear map between Banach spaces whose graph is closed is continuous.

Theorem 2.6 Hahn–Banach theorem
✓
#

Lean declarations

  • exists_extension_norm_eq

A bounded linear functional on a subspace of a normed space extends to the whole space with the same norm.

Theorem 2.7 Rademacher’s theorem
✓
#

Lean declarations

  • LipschitzWith.ae_differentiableAt
  • LipschitzWith.integral_lineDeriv_mul_eq

A Lipschitz function on \(\mathbb {R}^n\) is differentiable almost everywhere, and it can be integrated by parts against Lipschitz functions with compact support along every direction.

Theorem 2.8 Poincaré lemma on convex sets
✓
#

Lean declarations

  • Convex.exists_forall_hasFDerivAt_of_fderiv_symmetric

On an open convex set, a differentiable field whose derivative is symmetric is the gradient of a function.

Theorem 2.9 Lifting through covering maps
✓
#

Lean declarations

  • IsCoveringMap.existsUnique_continuousMap_lifts

A continuous map from a simply connected, locally path-connected space lifts through a covering map, uniquely once the lift of one point is chosen.

Theorem 2.12 Bump functions and convolution
✓
#

Lean declarations

  • ContDiffBump
  • HasCompactSupport.contDiff_convolution_left

There are smooth bump functions with compact support, and the convolution of a locally integrable function with a smooth compactly supported kernel is smooth.

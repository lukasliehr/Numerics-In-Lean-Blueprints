5 The abstract assembly

Definition 5.1 Analytic inputs
✓
#

Uses

  • Definition 3.5

Lean declarations

  • VP.AnalyticInputs

The analytic inputs for geometric data \(G\) of \(\Omega \) are the following statements.

  1. The cuts are Lebesgue null.

  2. If \(h\in L^2(\Omega )^3\) is curl free and divergence free, and \(v\in L^2(\Omega )^3\) satisfies \(v\cdot n=0\) and \(C_j(v)=0\) for all \(j\), then \((v,h)_{L^2(\Omega )^3}=0\).

  3. Every divergence-free \(u\) with \(F_i(u)=0\) for all \(i\) is a curl.

  4. A divergence-free \(\psi \) with \(\psi \times n=0\) (for \(\operatorname {curl}\psi =0\)) and \(F_i(\psi )=0\) for all \(i\) vanishes.

  5. If \(\psi \times n=0\) for a field \(\psi \) with \(\operatorname {curl}\psi =u\), then \(u\cdot n=0\).

  6. The gradient of a function with unit jump across a cut, extended across the null cuts, is curl free on \(\Omega \).

  7. If \(\psi \times n=0\) for a field \(\psi \) with \(\operatorname {curl}\psi =u\), and \(u\cdot n=0\), then \(C_j(u)=0\) for all \(j\).

Lemma 5.2 Necessary conditions
✓
#

Uses

  • Definition 3.4

Lean declarations

  • VP.divFree_of_hasWeakCurl
  • VP.zeroBoundaryFlux_of_hasWeakCurl
  • VP.hasWeakCurl_gradient
  • VP.divFree_of_zeroNormalTrace

A weak curl is divergence free and has zero flux through every boundary component. Gradients of \(H^1(\Omega )\) functions are curl free. A field with \(v\cdot n=0\) (for \(\operatorname {div}v=0\)) is divergence free.

Proof ▶

\(\operatorname {curl}\nabla \varphi =0\) and \(\operatorname {div}\operatorname {curl}\varphi =0\) for smooth test functions. The gradient of a cutoff of \(\Gamma _i\) vanishes near \(\partial \Omega \), so it is the gradient of a test function on \(\Omega \). The last statement follows by testing \(v\cdot n=0\) with \(q=\varphi \in C_c^\infty (\Omega )\).

Lemma 5.3 The gauge space
✓
#

Uses

  • Theorem 2.3

Assume the cuts are null, and let \(K\subset L^2(\Omega )^3\) be the orthogonal complement of the gradients of \(H^1(\Omega )\) functions and of the (extended) gradients of functions with unit jump across a cut. Then \(v\in K\) if and only if \(v\cdot n=0\) and \(C_j(v)=0\) for all \(j\), and \(\psi \) is a tangential potential of \(u\) if and only if \(\operatorname {curl}\psi =u\) and \(\psi \in K\). Under the analytic inputs, every element of \(K^\perp \) is curl free.

Proof ▶

The first two statements unfold the definitions; divergence freeness follows from Lemma 5.2. \(K^\perp \) is the closed span of the generating gradients, which are curl free by Lemma 5.2 and input 6; the curl kernel is closed.

Theorem 5.4 Assembly of Theorem 3.12

Lean declarations

  • VP.tangentialPotential_iff_of

If the analytic inputs hold, then \(\operatorname {div}u=0\) and \(F_i(u)=0\) for all \(i\) if and only if \(u\) has exactly one tangential potential.

Proof ▶

By input 3 there is \(\psi _0\) with \(\operatorname {curl}\psi _0=u\). Let \(\psi \) be the orthogonal projection of \(\psi _0\) onto \(K\). Then \(\psi _0-\psi \in K^\perp \) is curl free (Lemma 5.3), so \(\operatorname {curl}\psi =u\) and \(\psi \) is a tangential potential. If \(\chi \) is another one, \(\chi -\psi \) is curl free and lies in \(K\); hence it is divergence free with \((\chi -\psi )\cdot n=0\) and zero cut fluxes, and input 2 with \(v=h=\chi -\psi \) gives \(\lVert \chi -\psi \rVert ^2=0\). The converse is Lemma 5.2.

Lemma 5.5 The canonical tangential inverse
✓
#

Uses

  • Theorem 2.5
  • Theorem 5.4

Lean declarations

  • VP.fluxFree
  • VP.tangentialInverse
  • VP.tangentialInverse_continuous
  • VP.tangentialInverseL

The divergence-free fields with zero boundary fluxes form a closed subspace of \(L^2(\Omega )^3\). On it, the map sending \(u\) to its tangential potential is linear and continuous.

Proof ▶

Linearity follows from uniqueness. The graph of the map is the set of pairs \((u,\psi )\) with \(\operatorname {curl}\psi =u\) and \(\psi \in K\), which is closed; the closed graph theorem gives continuity.

Lemma 5.6 Orthogonality to the curl kernel
✓
#

Uses

  • Theorem 2.3
  • Definition 5.1
  • Lemma 5.2

Lean declarations

  • VP.AnalyticInputs.orth_curlKernel

Assume the analytic inputs. If \(u\cdot n=0\), \(C_j(u)=0\) for all \(j\), and \(w\) is curl free, then \((u,w)_{L^2(\Omega )^3}=0\).

Proof ▶

Write \(w=w_1+(w-w_1)\) with \(w_1\) the projection onto the orthogonal complement of the gradients of \(H^1(\Omega )\) functions. Then \(w-w_1\) is a limit of such gradients, orthogonal to \(u\) because \(u\cdot n=0\); and \(w_1\) is curl free with \(w_1\cdot n=0\), hence divergence free, so \((u,w_1)=0\) by input 2.

Lean declarations

  • VP.normalPotential_iff_of

If the analytic inputs hold, then \(\operatorname {div}u=0\), \(u\cdot n=0\) and \(C_j(u)=0\) for all \(j\) if and only if \(u\) has exactly one normal potential.

Proof ▶

Let \(T\) be the canonical tangential inverse of Lemma 5.5 and \(\psi \) the Riesz representative of the bounded functional \(f\mapsto (u,Tf)\) on the closed subspace of divergence-free fields with zero boundary fluxes; so \(\operatorname {div}\psi =0\) and \(F_i(\psi )=0\). If \(\operatorname {curl}w=c\), then \(c\) lies in that subspace and \(w-Tc\) is curl free, so \((u,w)=(u,Tc)=(\psi ,c)\) by Lemma 5.6. Taking test fields \(w\) gives \(\operatorname {curl}\psi =u\); taking \(w\in H^1(\Omega )^3\) gives \(\psi \times n=0\). Uniqueness is input 4. Conversely, inputs 5 and 7 give \(u\cdot n=0\) and \(C_j(u)=0\).

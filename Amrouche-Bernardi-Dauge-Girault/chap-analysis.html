7 Analysis on \(\mathbb {R}^3\)

Lemma 7.1 Mollification
✓
#

Uses

  • Theorem 2.12

Lean declarations

  • VP.moll
  • VP.moll_contDiff
  • VP.eLpNorm_moll_le
  • VP.tendsto_moll

There is a smooth, nonnegative, radial kernel \(\rho _t\) of unit mass supported in the ball of radius \(t\). For locally integrable \(f\), \(\rho _t*f\) is smooth; for \(f\in L^2(\mathbb {R}^3)\), \(\lVert \rho _t*f\rVert _{L^2}\le \lVert f\rVert _{L^2}\) and \(\rho _t*f\to f\) in \(L^2\) as \(t\to 0\).

Proof ▶

The kernel is built from a smooth profile of \(\lvert y\rvert ^2\). Young’s inequality gives the bound, and density of continuous compactly supported functions gives the convergence.

Lemma 7.2 Mollification commutes with weak derivatives
✓
#

Uses

  • Lemma 7.1

Lean declarations

  • VP.WeakCurl
  • VP.WeakDiv
  • VP.gradTest_moll
  • VP.curlTest_moll

If \(f\) has the weak gradient \(g\) on an open set \(U\) and the closed ball of radius \(t\) around \(x\) lies in \(U\), then \(\nabla (\rho _t*f)(x)=(\rho _t*g)(x)\). The same holds for weak curls.

Proof ▶

Derivatives of \(\rho _t*f\) are convolutions with derivatives of the kernel; at \(x\) the translated kernel is a test function on \(U\), and the weak identity applies.

Theorem 7.3 Weyl’s lemma for curl-free, divergence-free fields
✓
#

Uses

  • Lemma 7.2

Lean declarations

  • VP.weyl

Let \(U\subset \mathbb {R}^3\) be open and \(H\in L^2(\mathbb {R}^3)^3\) weakly curl free and divergence free on \(U\). Then \(H\) agrees almost everywhere on \(U\) with a smooth field that is classically curl free on \(U\).

Proof ▶

At points whose \(\tau \)-ball lies in \(U\), the mollification \(\rho _\tau *H\) does not depend on \(\tau \): the derivative of the radial kernel in \(\tau \) is a divergence, whose pairing with \(H\) vanishes because \(H\) is curl free and divergence free. Letting \(\tau \to 0\) identifies \(H\) with the smooth field \(\rho _\tau *H\) locally, and Lemma 7.2 shows that this field is curl free.

Lemma 7.4 Translations
✓
#

Uses

  • Lemma 7.1
  • Lemma 7.2

Lean declarations

  • VP.tendsto_translate
  • VP.integral_inner_grad_eq_zero

Translation is continuous in \(L^2(\mathbb {R}^3)\). If \(f\in L^2(\mathbb {R}^3)\) has a weak gradient \(g\in L^2\) and vanishes outside a compact subset of an open set \(U\), then \(\int _{\mathbb {R}^3}v\cdot g=0\) for every \(v\in L^2(\mathbb {R}^3)^3\) divergence free on \(U\).

Proof ▶

Continuity of translation follows by density of continuous compactly supported functions. For the second statement, \(\rho _t*f\) is a test function on \(U\) for small \(t\), with gradient \(\rho _t*g\), so \(\int v\cdot (\rho _t*g)=0\); let \(t\to 0\).

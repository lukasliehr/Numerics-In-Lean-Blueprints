Definition 2.2 Hausdorff measure
✓
#

Lean declarations

  • MeasureTheory.Measure.euclideanHausdorffMeasure

The \(k\)-dimensional Hausdorff measure on a Euclidean space, normalized to agree with Lebesgue measure on \(k\)-dimensional subspaces; it is the measure on the faces of the cells.

Theorem 2.5 Fundamental theorem of calculus
✓

Lean declarations

  • intervalIntegral.integral_eq_sub_of_hasDerivAt

\(\int _a^bf'=f(b)-f(a)\) when \(f\) has an integrable derivative on \([a,b]\).

Theorem 2.6 Bump functions and convolution
✓
#

Lean declarations

  • ContDiffBump
  • HasCompactSupport.contDiff_convolution_left

There are smooth bump functions with compact support, and the convolution of a locally integrable function with a smooth compactly supported kernel is smooth.

Theorem 2.7 Fundamental lemma of the calculus of variations
✓
#

Lean declarations

  • IsOpen.ae_eq_zero_of_integral_contDiff_smul_eq_zero

A locally integrable function on an open set whose integrals against all smooth compactly supported functions vanish is zero almost everywhere.

Theorem 2.8 Linear maps of finite-dimensional spaces
✓
#

Lean declarations

  • LinearMap.injective_iff_surjective

A linear endomorphism of a finite-dimensional vector space is injective if and only if it is surjective.
